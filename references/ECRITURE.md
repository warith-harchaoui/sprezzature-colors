# ECRITURE.md

Standards de prose française pour sprezzature-colors.

Actualisez la version complète avec :

```
gh gist view 7cc42b038e86c5195ec09f0531111ba4
```

Règles clés : pas de tirets de ponctuation, pas de tics de machine,
phrases courtes, registre sobre. Jamais : « Par ailleurs », « De plus »,
« incontournable », « À l'heure où », « De nos jours ».
